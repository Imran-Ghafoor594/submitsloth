# 90-second demo plan

1. Show the 3-page report and two screenshots in `examples/before/`.
2. Paste `examples/instructions.txt`. With a real configured open-weight model, generate the checklist. If using the hand-written sample, identify it as such.
3. Confirm/correct each requirement against the brief. Explain that the model interprets text; code checks measurable constraints.
4. Upload the original files. Show the page-limit and screenshot-count failures and the evidence.
5. Replace the report with the 2-page fixed report and add the missing third screenshot.
6. Re-run. Show that human judgment requirements still need review.
7. Preview filenames, acknowledge unresolved review items, download the ZIP and inspect its contents.

## Evidence to collect before submission

- Record real manual preparation time and app-assisted preparation time on the same tasks.
- Use 10 representative briefs and annotate the true requirements before comparing AI output.
- Count supported requirements extracted correctly, missed requirements and invented requirements separately.
- Record model ID, hosting location, license, failures, latency and actual inference costs.
- Test real provider errors and image OCR on the final host.
- Do not claim a local/private workflow if you use external inference or hosted file processing.

## Write-up structure

- The specific last-minute submission problem you experienced.
- What the tool does and which effort it removes.
- A before/after demonstration with evidence.
- Why an open-weight model matters: provider swapping, local inference possibility and transparent processing.
- What deterministic checks do, what the model does, and what still needs human judgment.
- Real test results and known limitations.
- Repository, live demo/video, setup and exact model instructions.
